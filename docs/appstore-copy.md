## 0. この案の前提

競合の課金者レビュー（一次情報）から、勝てる一文を1つに絞った。

> **「AIが勝手に分量を変えない、冷蔵庫アプリ。」**

根拠にした競合の★1レビュー：

| 競合 | 規模 | ★1で繰り返される不満 |
|---|---|---|
| CookGo | 10万DL・9,015件 | 「砂糖大さじ1→砂糖小さじ1のように致命的な間違いが当たり前。ほぼ全てのレシピに大きな間違いがあります」 |
| pecco | 50万DL・2,206件 | 「冷蔵庫にある物を入力して検索したのに、ない物でのレシピしか出てこなかった。そく削除した」 |
| クラシル | 757,913件 | 「Web版では人数で調節できるのにアプリ版は無い。プレミアム解約、アンインストール」 |
| DELISH KITCHEN | 500,532件 | 人数変更は公式に「提供しておりません」 |

つまり **不満の中身が3つとも CookSync の実装で既に埋まっている**。追加開発ゼロで言える。

### 書いてはいけないこと（調査で潰れた／未実装）

- ❌「動画URLからレシピ」を**単独の看板にする** … CookGo が10万DLで先行。競合ゼロではない。機能として並べるのは可。
- ❌「冷蔵庫にあるもので献立」を**単独の看板にする** … pecco がサブタイトルで占有済み。真正面は負ける。「本当に守る」という限定つきなら可。
- ❌「レシートを撮るだけ」 … **レシート読み取りは未実装**。書かない。
- ❌ 主訴求を食品ロスにする … 夕食の悩み1位は「献立を考えること」65.8%。家庭の食品ロスのうち期限切れ廃棄は18%だけ。食品ロスは**10月（食品ロス削減月間）のPRフック専用**に回す。

## 4. 説明文

### プロモーションテキスト（170字以内・審査なしで差し替え可）

```
レシピアプリで一番困るのは、材料の分量が間違っていること。CookSyncは、読み取れなかった分量を「読み取れなかった」と書きます。参考にしたページのURLも必ず残します。冷蔵庫にあるものだけで作る献立と、手順の中の分量まで書き換わる人数換算つき。
```

（124字）

### 説明文（4,000字以内）

```
■ AIが勝手に、分量を変えない。

レシピアプリで一番困るのは、作りはじめてから材料の量が違うと気づくことです。
CookSyncは、AIが読み取れなかった分量を推測で埋めません。

・読み取れなかった材料は「⚠ 分量が読み取れなかった材料：〇〇」と名前を挙げて警告します
・どれくらい自信があるかを3段階で表示します（確度が低いときは「元の動画・写真で確認してください」と書きます）
・参考にしたページのURLを必ず残します。出典が無いレシピはAIに出させません

取り込んだレシピは確認画面を挟んでから保存します。
材料・手順・読み取れなかった箇所を見て、納得してから残せます。


■ 「冷蔵庫にあるものだけ」を、本当に守る。

献立提案の初期設定が「在庫だけで作る」です。
塩・しょうゆなどの基本調味料以外は、冷蔵庫に無い食材を使わせません。

・買い足したい日は「買い物してもOK」に1タップで切り替え
・足りない分だけを「1パック」「1束」など店で買える単位で買い物リストへ
・作り終わって「作った」を押すと、使った分だけ在庫が減ります（取り消しもできます）


■ 手順の文章の中の分量まで、書き換わる。

1〜4人分を選ぶと、材料表だけでなく手順の文章とkcalまで換算します。

・「大さじ1」「80〜90g」「1と1/2個」も、読める形のまま換算
・手順の「5分煮る」などの時間や温度は換算しません（分量だけを直します）
・増やすときは「調味料は7〜8割から入れて味を見て」という注意も表示します


■ レシピの入れ方は、3つ。

1. AIに提案してもらう
   冷蔵庫の食材と、気分・調理時間・人数から3案。期限が近い食材から優先して使います。

2. 動画のURLから
   YouTube・TikTokの料理動画を貼るだけ。概要欄と字幕から材料と手順を書き起こします。

3. 写真から
   レシピ本のページ、SNSのスクリーンショット、手書きメモを4枚まで。
   順番がバラバラでも、調理の進み方から並べ直します。

どの入れ方でも、読み取れなかった分量と出典の扱いは同じです。


■ そのほかの機能

・写真で在庫登録 — 冷蔵庫や食材を撮るだけ。食材名を読み取り、賞味期限とカテゴリを自動で推定します
・賞味期限の見える化 — 近い・そろそろ・余裕を色分け。期限が近い順に並びます
・自動タイマー — 手順の「○分」を読み取り、ワンタップで使えるタイマーに。複数同時に動かせます
・好みの学習 — 星評価で提案が自分仕様に。直近に作った料理は自動で避けます
・余った食材の保存方法 — 使い切れなかった分の保存のしかたをレシピごとに表示します


■ 料金

基本無料です。原価のかかるAI機能だけ、月ごとの利用回数に上限があります。
（AIレシピ探索 8回／写真で在庫登録 25回／写真・動画からレシピ取り込み 5回）
人数の換算、在庫管理、買い物リスト、タイマーはAIを使わないため、回数制限はありません。
```

## 5. スクリーンショットで見せる順番（案）

差別化 → 使い方の順。1枚目で「分量」を必ず見せる。

1. **取り込み確認画面**（`⚠ 分量が読み取れなかった材料：…` が出ている状態）
   キャプション：「AIが勝手に、分量を変えない」
2. **レシピ詳細の「参考にしたページ」**（URLリンクが並んでいる状態）
   キャプション：「どこから来たレシピか、必ず残る」
3. **献立ウィザードの「在庫だけで作る」チップが選択された状態**
   キャプション：「冷蔵庫にあるものだけ、を本当に守る」
4. **レシピ詳細の人数セレクタ＋手順**（2人分→4人分で手順文の数値が変わっているのが分かる並び）
   キャプション：「手順の中の分量まで書き換わる」
5. **冷蔵庫リスト**（期限の色分け）
   キャプション：「期限が近い順に並ぶ」
6. **買い物リスト**（1パック等の単位）
   キャプション：「足りない分だけ、買える単位で」

## 6. まだ言えないこと（実装が足りない主張）

提出テキストに**書かないこと**。実装されたらこの節から上へ移す。

| 言いたいが言えない | 理由 |
|---|---|
| レシートを撮るだけで在庫登録 | レシート読み取りは未実装（写真からの食材認識はあるが、レシートに特化した処理は無い） |
| 何人分でも対応 | 人数セレクタは **1〜4人分** の4択（`RecipeDetail.tsx` / `MealWizard.tsx`）。「何人分でも」は誇張 |
| 分量が絶対に正しい | 保証していない。あくまで「読めなかったことを隠さない」「出典を残して確認できる」まで |
| 栄養計算・PFCバランス | kcal の換算のみ。栄養素の計算は無い |
| 家族・複数人で在庫を共有 | 共有機能は無い |
| 献立の週間プラン自動作成 | 献立記録（作った記録）はあるが、週次の自動プランニングは無い |
