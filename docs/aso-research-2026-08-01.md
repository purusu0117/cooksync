# App Store 検索まわりの実地調査（2026-08-01）

**すべて実測値。推測は入れていない。**
WebSearch がセッション枠切れだったため、Apple / Google の公開APIを直接叩いて取得した：

- Apple App Store 検索サジェスト（`search.itunes.apple.com/.../MZSearchHints.woa/wa/hints`、storefront 143462＝日本）
  → 返る順序が**ストア内の検索人気順**。ASOで最も信頼できる需要シグナル。ただし**絶対ボリュームは非公開**で順位までしか分からない。
- iTunes Search API（`country=jp&entity=software`）→ 競合のアプリ名・サブタイトル・評価件数の原文
- Google サジェスト（`hl=ja&gl=jp`）

### この調査で一番効いた発見：需要ゼロの語に供給が集中している

- **「余り物」→ サジェスト候補ゼロ**（アプリ名1件だけ＝候補が枯渇してAppleが仕方なくアプリ名を出している状態）
- **「残り物」→ 完全に空**
- **「限界食材」→ 完全に空**
- **「ai レシピ」→ キーワード候補ゼロ**（アプリ名のみ）。一方**「ai 献立」は実在**。AI系は「レシピ」より「献立」に需要がある。
- **「冷蔵庫レ」（スペースなし）→ 候補ゼロ**。実需は**スペース入りの「冷蔵庫 レシピ」**側にある。

Google 側では「残り物 レシピ」に検索意図があるのに、**App Store 内では実測ゼロ**。
にもかかわらず 冷蔵庫シェフ・スマシェフ・Harapeko・ピタレシ・へらしぴ が
揃って名前欄に「余り物／残り物」を入れている。**名前欄の文字を割く価値はない。**

## 3. CookSync が取りに行くべき語

判定軸＝**(A) Appleサジェストに実在する（需要あり）× (B) 名前欄で押さえている強豪がいない**

### ★★★ 最有力

1. **「冷蔵庫管理アプリ」「冷蔵庫管理」** — サジェスト**1位と3位**。なのに名前欄に入れているのは フリレコ(3件) と タベキル(11件) だけ。pecco も CookGo も入れていない。この領域の最大手 Limiter(6,708件) ですら名前は「賞味期限・在庫管理」で**「冷蔵庫」の語がない**。**需要1位で競合ゼロ。**
2. **「冷蔵庫 在庫」「食材在庫管理」** — 「冷蔵庫」7位・「食材」2位。競合（うちメモLT・在庫ノート・Limiter）は**いずれもレシピ提案を持たない**。逆にレシピ提案系は誰も「在庫」を名乗っていない。
3. **「レシピ 取り込み」** — 名前で押さえているのは **CookGo ただ一社**。しかも CookGo は「冷蔵庫」を名乗っていない。CookSync が「取り込み」×「冷蔵庫」を両取りすれば **CookGo と pecco の中間の空白地帯を単独で取れる。**
4. **「献立 自動作成／自動提案」** — Googleで自動作成/自動生成/自動提案/1週間 と枝が豊富。名前欄に「自動作成」を持つのは AutoMenu(1件) のみ。DELISH はサブタイトルには入れているが**名前欄には入れていない**。

### ★★ 有力

5. **「AI献立」**（「AIレシピ」より優先。後者はキーワードとして存在しない）
6. **「賞味期限」×「レシピ／献立」の交差** — 期限側の強豪はレシピを持たず、レシピ側の強豪は期限を持たない。両方名乗るのは pecco だけでそれが3年放置。**事実上の空白地帯。**
7. **「使い切り」「食材 使い切り」** — 需要は細いが競合が ツカイキリ(0) / レシパ(1) のみ。ロングテール補助語。
8. **「無料」** — Google・Apple双方で高頻度なのに、この領域の主要アプリはほぼ誰も名前に入れていない。

### ✕ 避ける語

- **「余り物」「残り物」** — App Store内の検索需要が**実測ゼロ**。説明文止まりでよい。
- **「食品ロス」** — サジェスト上位はレット(151,117件)・TABETE・クラダシで**検索意図が「安く買う」＝別物**。流入しても刺さらない。
- **「冷蔵庫」単体** — 結果面がゲーム（冷蔵庫整理3D・脱出）と家電メーカー公式に割れている。**必ず修飾語とセットで。**
- **「レシピ保存」「レシピ管理」** — 大需要だが専業が10本以上ひしめく最激戦区で、かつ CookSync の差別化（冷蔵庫起点）が効かない土俵。

## 4. この調査の限界（正直に）

- Apple の hints は**順位のみ**。絶対検索ボリュームが要るなら Sensor Tower / AppTweak 等の有料ASOツールが必要。
- iTunes Search API の並び順は実際のApp Store検索結果と**近似であって一致ではない**。競合の強さ判定には評価件数を併用した。
- 「限界食材レシピ」の正体（Webサービスか Android専用か SNS発企画か）は WebSearch 枠切れで未特定。ASO上は無視してよいという結論は変わらない。
